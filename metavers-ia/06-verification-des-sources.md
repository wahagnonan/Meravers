## 3. Limites reconnues

1. Certains chiffres reposent sur des extraits de recherche plutôt que la lecture intégrale des pages (atténué par corroboration croisée).
2. Les rapports `01-innovations.md`, `02-secteurs.md` et `03-adoption.md` proviennent d'un travail antérieur : chaque affirmation y est référencée (URL + date), mais les ~100 chiffres n'ont pas tous été re-vérifiés individuellement dans la présente session.
3. Sources anciennes identifiées comme telles : McKinsey (2022), chiffres Horizon Worlds (2022, plus de publication officielle depuis), étude concerts Fortnite (2021-2022).
4. Les pages web évoluent : citer avec date d'accès. Pour un usage académique, télécharger les PDF officiels (rapports AIE, WEF, PwC disponibles en téléchargement direct).
5. Aucun chiffre du dossier n'est une estimation inventée : chaque valeur est attribuée à une source nominative avec URL.

## 4. Recommandations d'usage

- **Citation académique** : privilégier Tier 1-2, mentionner « projection » pour Tier 3, ajouter la date de consultation.
- **Contestation possible** : si une donnée est contestée, vérifier la source primaire via l'URL citée avant toute correction.
- **Mise à jour** : les chiffres de marché (Tier 1) évoluent chaque trimestre (résultats Roblox, Meta, IDC) — dater toute republication.
